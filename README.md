# RAM Monitor

**RAM Monitor** — Android-приложение для мониторинга оперативной памяти устройства, сбора статистики и анализа динамики использования памяти.

## Возможности

- **Главная** — отображение текущего состояния оперативной памяти устройства и создание снимков показателей.
- **Приложения** — просмотр установленных приложений, поиск и фильтрация по типу.
- **Аналитика** — графики изменения показателей памяти за 1, 7 и 30 дней.
- **Обнаружение подозрений на утечки** — анализ динамики показателей памяти и отображение приложений, требующих дополнительного внимания.
- **Фоновый мониторинг** — периодический сбор данных с помощью WorkManager.
- **Локальное хранение** — сохранение собранных данных в базе Room.

## Используемые технологии

- Kotlin
- Android SDK
- XML Layouts
- Room Database
- WorkManager
- UsageStatsManager

## Архитектура и данные

Приложение разделяет сбор показателей, хранение данных и отображение информации. Для локального хранения используются сущности Room, а фоновый сбор выполняется отдельной задачей WorkManager.

## Ограничения

Android ограничивает доступ обычных приложений к статистике памяти других процессов. Поэтому часть показателей PSS/RSS относится к собственному процессу RAM Monitor. Раздел обнаружения утечек формирует эвристические подозрения на основании динамики показателей и не является доказательством утечки памяти.
